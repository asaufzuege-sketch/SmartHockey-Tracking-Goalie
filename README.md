# SmartHockey Tracking Goalie

Goalie-only SmartHockey tracker for live shot logging, save maps, and season exports.

## Workflow

1. Open **Goalie Selection** and tick up to 10 goalies.
2. The first checked goalie, or the one checked most recently, becomes the active goalie for the live **Game Center** table.
3. In Game Center:
   - tap the half rink or red goal to place a **grey save marker**
   - long press the half rink or red goal to place a **red goal marker**
4. Goalie table counts are driven by half-rink markers: red goal markers add **Shots + Goals**, while grey save markers add **Shots + Saves**.
5. Use **Export Season** to enter opponent difficulty and goalie minutes, then save the game into season data.
